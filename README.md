# futuretoday-forms

Сервис форм отклика: менеджер собирает форму в админке, публикует ее по уникальной ссылке, студент заполняет форму по этой ссылке, менеджер видит ответы и воронку заполнения. Тестовое задание, стек Node.js и express, данные хранятся внутри проекта.

Статус: каркас проекта. Код сервиса пишется по плану, полная инструкция запуска и разбор решения появятся в этом файле.

## Запуск

Две команды из корня репозитория:

```
npm install
npm start
```

Сервис отвечает на `http://localhost:3000`, админка на `http://localhost:3000/admin`. Порт задается переменной окружения `PORT`, например `PORT=4000 npm start`.
